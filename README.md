# Trackflow (repo root)

Repository ini sudah dirapikan menjadi tiga area utama:

- `frontend/` — semua kode frontend (UI, konfigurasi bundler, `package.json`, `public/`, `src/`, dsb.).
- `backend/` — folder placeholder untuk server/API.
- `ai/` — folder placeholder untuk eksperimen AI.

Menjalankan frontend (dari root):

```powershell
cd frontend
npm install
npm run dev
```
