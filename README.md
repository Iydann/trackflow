# Trackflow (repo root)

Repository ini sudah dirapikan menjadi tiga area utama:

- `frontend/` — semua kode frontend (UI, konfigurasi bundler, `package.json`, `public/`, `src/`, dsb.). README asli proyek dipindah ke `frontend/README.md`.
- `backend/` — folder placeholder untuk server/API. Saat ini kosong.
- `ai/` — folder placeholder untuk eksperimen AI/ML. Saat ini kosong.

File/konfigurasi global seperti `.gitignore`, `.env` (jika ada), dan pengaturan editor tetap berada di root.

Menjalankan frontend (dari root):

```powershell
cd frontend
npm install
npm run dev
```

Jika Anda ingin saya juga memindahkan `node_modules/` ke `frontend/` atau menyesuaikan path lain, beri tahu saya.
