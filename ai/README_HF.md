# TrackFlow AI - Vehicle Detection & Tracking

FastAPI server for vehicle detection and tracking using YOLOv8.

## Endpoints

- `GET /` - API info
- `GET /health` - Health check  
- `POST /process` - Process video for vehicle tracking
- `GET /docs` - API documentation (Swagger UI)
